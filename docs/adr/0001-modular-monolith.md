# ADR-0001. Модульный монолит вместо микросервисов

**Статус:** принято

## Контекст
Хакатон: несколько дней, команда 1–5 человек, демо должно работать с первого раза. При этом проект должен расти: поиск, бронирование, платежи, уведомления.

## Решение
Один деплой, внутри — модули Spring Modulith (`intent`, `search`, `catalog`, `shared`). Модуль публикует API типами базового пакета, реализация — во внутренних пакетах. Нарушение границ ломает `ModularityTests`.

## Последствия
- Нет сетевых вызовов между модулями: нет распределённых отказов, проще отладка и демо.
- Границы проверяются автоматически, а не на ревью.
- Вынос модуля в сервис — механическая операция: API уже изолирован, общение переводится на события/HTTP.
- Минус: общий пул соединений и общий релизный цикл. Для текущего масштаба приемлемо.
