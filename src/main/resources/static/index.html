Расскажите гостям об отеле. Мы доверяем вашим данным, но сверяем их с картой: расхождение увидит гость — поэтому лучше указать как есть. Подтверждённые данные поднимают отель в выдаче для тех, кому это важно.

Добавить характеристику текстом

Опишите словами — система соберёт правило из готовых инструментов (поиск на карте, расстояние, количество) и посчитает его для всех отелей региона. Например: «аптека в 5 минутах», «нет ночных клубов рядом», «много кафе рядом».

Агент данных

Следит, чтобы выводы опирались на данные. Если для характеристики в снимке OpenStreetMap нет нужных объектов, агент не пишет «рядом нет», а предлагает их докачать. Ничего не скачивается без вашего решения.
